# Fock-embedding spike

This directory is the exploratory and validation corpus that led to Pymablock's
structured second-quantized embedding implementation. It deliberately retains several
older execution strategies as independent references; production code lives in
`pymablock`, not here.

The resulting package API treats an encoding as a structured form of
`subspace_eigenvectors`:

```python
q1, q2 = levels("q1 q2", 2)
embedding = occupation_embedding({a1: q1, a2: q2, coupler: 0})

H_tilde, U, U_adjoint = block_diagonalize(
    [H0, capacitive_coupling],
    subspace_eigenvectors=embedding,
)

H4 = H_tilde[0, 0, 4]  # A NumberOrderedForm for this binary target.
```

Finite nonbinary targets use Pymablock's existing outer SymPy-matrix convention.
Binary spin and direct fermion targets remain number-ordered operators. The package
backend uses weighted NOF transitions and formal complement maps without enumerating
the ambient source Hilbert space.

## Historical prototype API

The original isolated experiment added an embedding from a target operator algebra
into the source Fock space:

```python
q1, q2 = levels("q1 q2", 2)
encoding = occupation_map({a1: q1, a2: q2, coupler: 0})

H_tilde, U, U_adjoint = block_diagonalize(
    [H0, capacitive_coupling],
    encoding=encoding,
    to_order=4,
)

H4_matrix = H_tilde[4].matrix
H4_spins = H_tilde[4].pauli()
```

There are now three execution backends. `block_diagonalize` is the finite-state
reference implementation. `block_diagonalize_algebraic` runs the same Pymablock
recurrence over formal embedding columns and specialized packed/Boolean domains.
`block_diagonalize_maps` runs that recurrence over a sparse map domain:

```python
H_tilde, *_ = block_diagonalize_maps(
    [H0, capacitive_coupling],
    encoding=encoding,
    to_order=4,
)

H4 = H_tilde[4]
H4_matrix = H4.matrix()
H4_spins = H4.pauli()
```

All three calls use the same historical spike API. They remain useful as independent
finite-state, packed-algebraic, and explicit-map references. The package implementation
uses the same projector semantics, but intentionally does not expose these backend
types or result wrappers.

Fermion-to-fermion reductions do not pass through target coordinates. The target
generators are part of the embedding itself:

```python
f = tuple(FermionOp(f"f{i}") for i in range(3))
encoding = fermion_embedding(
    {
        a_up: 1,
        a_down: 1,
        **{b[i, UP]: f[i] for i in range(3)},
        **{b[i, DOWN]: 0 for i in range(3)},
    },
    number=(0, 1, 2),
)

H_tilde, *_ = block_diagonalize([H0, hopping], encoding=encoding, to_order=4)
assert H_tilde[4].generators == f
```

Here `H_tilde[n]` is a `FermionOperator` on the Fock algebra generated by `f`.
Its finite matrix is an execution and inspection view, not the public identity of the
target space. The embedding includes the graded Fock-space phase needed when frozen
occupied source modes precede mapped modes.

The Hubbard plaquette uses the same format without enumerating its sixteen retained
states:

```python
spins = levels("s0:4", 2)
encoding = occupation_map({
    mode: occupation
    for i in range(4)
    for mode, occupation in (
        (c[i, UP], spins[i]),
        (c[i, DOWN], 1 - spins[i]),
    )
})
```

## Finite-state reference backend

- Existing SymPy boson and fermion Hamiltonians remain unchanged.
- `occupation_map` specifies `W` by source occupations as expressions in finite target
  coordinates. It compiles and inverts the finite map once.
- Number-ordered source terms act directly on occupation tuples; SymPy is retained only
  for scalar coefficients.
- A breadth-first search constructs the source states with distance at most
  `to_order // 2` from the retained image. For a Hermitian first-order perturbation,
  these are all states that can occur on a returning path through `to_order`.
- The encoding is lowered to a retained-subspace matrix `W`. The finite source
  Hamiltonian, `W`, and an exact diagonal resolvent are passed through Pymablock's
  existing implicit `subspace_eigenvectors` path.
- Results carry target labels and may be expanded in target Pauli strings.
- Direct fermion embeddings carry named target generators and may select one or more
  target particle-number sectors.

Dense object arrays for the compiled finite graph are intentional spike scaffolding.
A package implementation can replace them with transition-backed operators without
changing the embedding interface, projector formalism, or block-diagonalization
recurrence.

## Algebraic backend

The algebraic backend keeps the embedding `W` formal. Complement vectors are sums of
terms `Q X W A`. The representation of `X` follows its local algebra:

- purely fermionic sources use packed monomial keys;
- bosons and ladders remain in `NumberOrderedForm`;
- the binary target spin algebra uses the same keys with commuting cross-mode
  statistics;
- a small nonbinary target is represented by its exact retained finite matrix;
- SymPy expressions are held only as scalar coefficients.

The embedding maps complete source monomials, rather than individual generators, to
`W† X W`. This is required because the pullback is not an algebra homomorphism: an
individual operator may leave the encoded space even when a product returns to it.
Packed source monomials are projected by direct Boolean occupation action and cached
independently of their scalar coefficients.

Target number projectors use a sparse Boolean polynomial domain. A monomial is an
integer mask and multiplication is bitwise OR, implementing `n_i**2 = n_i` without
SymPy interpolation. The Sylvester solver fixes transition support using affine
occupation constraints and represents any remaining occupation-dependent inverse in
the same Boolean domain.

The existing Pymablock block recurrence operates on four typed objects: target blocks,
formal complement columns and rows, and complement endomorphisms. Its Sylvester hook
divides each definite source/target shift by the corresponding symbolic energy
difference. A binary-target matrix is materialized only when `.matrix()` is explicitly
requested for validation or inspection. A nonbinary finite target is a matrix
throughout, but its dimension is only the retained dimension and is independent of the
source closure.

The prototype requires diagonal source `H0`. It reproduces the fourth-order
tunable-coupler result and the Hubbard ring term `40 t**4 / U**3` without source-state
closure. It now also accepts finite multilevel targets. General target boson and ladder
operator algebras, and the direct `FermionEmbedding` API, remain representation
extensions; they do not require changing the formal `Q X W A` block algebra.

## Sparse map backend

The map backend generalizes the storage model of `NumberOrderedForm`. A finite target
operator is a dictionary whose structural key

```text
MapKey(input_state, output_state)
```

means `|output_state><input_state|`; the value is a held SymPy scalar coefficient.
Addition combines equal keys, multiplication joins maps on their intermediate state,
and adjoint reverses the map. Dense matrices are created only by `.matrix()`.

The embedding itself is stored algebraically rather than as one entry per state. For
example,

```python
m = levels("m", 4)
encoding = occupation_map({a: 2 * m})
```

becomes one occupation-map term `m -> 2*m`. Consequently `W† a W = 0`, while
`W† a**2 W` is a lowering map on `m` with the correct bosonic square-root
coefficients. Products, frozen occupations, complementary spin occupations such as
`n_down = 1 - n_up`, and direct fermion-to-fermion embeddings use this same format.

`block_diagonalize_band_maps` tests a hybrid representation in which the embedding is
an `AffineBand` with independent parameterizations of its left and right occupations.
For example, `n = 2*m` is stored as

```text
parameters: m
left:       n = 2*m
right:      m
support:    m = 0, 1, 2, 3
```

Adjoint swaps `left` and `right`; it never tries to invert `n = 2*m`. An off-diagonal
map is a sum of

```text
left operator ◦ affine bridge ◦ retained operator
```

components. Second-quantized actions are `TensorOperator` objects: sparse sums of
products whose native factors may be `NumberOrderedForm` or packed binary operators.
A bosonic `H_AA` therefore remains a NOF on the right of a band, while a mixed
boson-fermion operator can use independent NOF and packed factors without inventing
one common monomial format.

Finite retained indices use Pymablock's existing outer-matrix convention. Finite state
maps are native immutable SymPy matrices, not `StateMapForm`, `FiniteTargetForm`, or
matrix factors inside `TensorOperator`. The surrounding target space supplies the
interpretation of row and column indices. Construction repeatedly merges equal left
factors and equal right factors. Inner products lazily compile a monomial contraction
index, but do not replace the stored components. This separates the readable map
format from the specialized representation used by the hot contraction.

The production off-diagonal block delegates its storage and arithmetic to
`pymablock.operator_map.OperatorMap`. One stored term

```text
(X, A)
```

represents `Q X W A`, where `X` is a source `NumberOrderedForm`, `A` is an operator on
the retained space, and `Q = 1 - W W†`. The map's embedding backend supplies its
explicit complement and retained spaces and the pullback `W† X W`. Equal source
factors are combined without materializing either Hilbert space.

Applying a source operator on the left uses the exact identity
`Q S Q X W A = Q S X W A - Q S W (W† X W) A`. Inner products use the corresponding
pullback identity. The reverse block is an adjoint view, and complement endomorphisms
remain lazy sums, products, source actions, and rank-one maps. Bosonic, ladder,
fermionic, and spin amplitudes are supplied by the common weighted-transition layer.

The explicit state-map implementation below instead composes and joins virtual
occupation states directly. It is retained as a performance and correctness reference,
not as the package representation.

The present spike enumerates the finite retained target basis and the virtual states
that actually occur as map outputs. It never constructs or indexes the complete
virtual source Hilbert space. This is the practical boundary needed by the current
applications: four qubits, three spin-1 states, and selected fermionic number sectors
are finite, while their bosonic and Floquet ambient spaces need not be.

`block_diagonalize_factored_maps` retains the previous `Q X W A` representation as a
reference implementation. `block_diagonalize_maps` uses explicit composed rules, and
`block_diagonalize_band_maps` uses the hybrid format above.

Cold timings below are medians of three fresh Python processes on the development
machine. Model construction is outside the timer and the requested effective matrix is
fully materialized.

| model | order | finite graph | factored maps | hybrid bands | composed maps |
|---|---:|---:|---:|---:|---:|
| tunable coupler | 4 | 0.461 s | 0.506 s | 0.690 s | 0.233 s |
| Hubbard ring | 4 | 0.492 s | 0.920 s | 0.769 s | 0.053 s |
| spin-1 Floquet | 2 | 0.131 s | 0.155 s | 0.186 s | 0.097 s |
| Crépel-Fu two-star | 4 | 21.055 s | 3.563 s | 3.295 s | 1.473 s |

The composed maps are faster than both references on all four examples. Ring exchange
shows the largest gain because matching virtual output occupations turns the inner
product into a direct sparse join. It also agrees with the finite reference in every
retained sector rather than only for the ring matrix element.

The hybrid format is competitive with factored maps, but does not yet outperform the
explicit composed rules at these small retained dimensions. Moving finite matrices
from an inner tensor factor to Pymablock's outer matrix layer removes representation
machinery and modestly improves the ring factored and hybrid paths; it does not remove
the cost of SymPy matrix arithmetic itself. Explicit map joins are essentially
unchanged. The hybrid format's current value is that it preserves native tensor factors
and avoids source-space enumeration; larger retained or genuinely algebraic target
spaces are needed to test whether that structure offsets matrix overhead.

Binary NOF terms now use one packed monomial for all spin and fermion modes, together
with a basis-level bit mask selecting the anticommuting modes. This is the actual
`NumberOrderedForm` storage: each key is `(infinite shifts, packed binary monomial)`;
the historical full power tuple is a decoded compatibility view. There is no parallel
packed object or global coefficient linearization. A factorized spin/fermion key is
25--30% faster on artificial dense monomials, but the joint key is 9--24% faster on the
sparse low-degree products representative of these perturbation expansions, and
requires only one sparse join. Run
`python -m notes.encoding_spike.benchmark_binary_storage` to reproduce that comparison.

## Synthetic spin-1 Floquet benchmark

`synthetic_spin_floquet()` implements the driven cavity-qubit construction of
[Roy et al., PRX 15, 021009 (2025)](https://arxiv.org/abs/2405.15695) without the
appendix's sequence of rotating-wave reductions. The model makes only the carrier
rotation. Its source algebra contains a cavity boson `c`, a bilateral Floquet ladder
`ell`, and the dressed two-level ancilla `d`; positive and negative powers of `ell`
retain every drive-comb Floquet index.

For the default `s=1`, the embedding retains the three resonant Sambe states

```text
|m> = |cavity=m, Floquet=0, dressed=0>,    m = 0, 1, 2.
```

The target is consequently one explicit 3x3 matrix, while virtual cavity, ancilla, and
Floquet excursions remain second-quantized source operators. The first-order result is
the paper's matrix-element-modified cavity drive,

```text
<m-1|H1|m> = epsilon/2 * sqrt(m)
              * cos((phi_m - phi_(m-1))/2) * exp(i varphi).
```

With `phi_0 = phi_1 = 0` and `phi_2 = pi/2`, both nonzero upper-diagonal elements are
`epsilon exp(i varphi) / 2`, producing the spin-1 generator. The finite-state backend
uses 3 retained plus 27 virtual states through second order. The two implicit backends
instead evaluate the same Pymablock recurrence with formal source columns and a finite
3x3 target. The tests compare all three first-order matrices symbolically and their
second-order corrections at an exact generic parameter point.

## Crépel-Fu benchmark

`crepel_fu_triangle()` implements the local virtual process in
[Crépel and Fu, PNAS 119, e2117735119 (2022)](https://doi.org/10.1073/pnas.2117735119).
One filled spinful A orbital couples to three B orbitals; the target consists directly of
the three equal-spin doped fermions on B. Static Hartree energies from the omitted filled
A neighbors are retained. This cluster is used only for the published second-order
check.

At second order the calculation reproduces

```text
t      = t0**2 / (Delta + V0)
t + λ  = t0**2 / Delta
λ      = t0**2 * (1/Delta - 1/(Delta + V0))
```

Fourth order uses `crepel_fu_two_star()`: two filled A orbitals and the union of
their B neighbors. The stars share B1, so the cluster has 2 A plus 5 B sites, or
14 spin-orbital source modes. Its target has five equal-spin doped-fermion modes
restricted to zero, one, or two particles (16 retained states). The finite graph
reaches another 555 virtual states.

The matrix element from B0 to B3 follows the connected four-edge path
`B0-A0-B1-A1-B3`. It vanishes through second order and at fourth order equals

```text
h_range-2^(4)
  = -t0^4 (2 Delta^2 + 4 Delta V0 + V0^2)
      / [2 (Delta + V0)^3 (Delta + 2 V0)^2].
```

At the exact rational sample `Delta=10, V0=2, UA=7, UB=11, t0=1`, this is
`-71 / 169344`. No one-A subcluster connects B0 and B3, so this particular
matrix element is already its connected-cluster contribution. Reconstructing every
fourth-order lattice operator would additionally require enumerating all connected
four-bond clusters and subtracting their proper subclusters.

## Validation

Run:

```bash
pixi run -e latest-no-mumps pytest notes/encoding_spike -q
pixi run python -m notes.encoding_spike.demo
pixi run python -m notes.encoding_spike.benchmark_maps
```

The packed binary kernel is a private pure-Python module, so this spike has no
dependency on the sibling `packed_fermions` project. Its three-function boundary can
still be accelerated later without changing `NumberOrderedForm`.
`profile_algebraic.py` is the entry point for either `cProfile` or Python 3.15's
sampling profiler.

The tests check:

- the three-boson tunable-coupler graph closes to 44 states through fourth order;
- direct and second-order mediated qubit exchange amplitudes;
- reconstruction of the coupler effective matrix from target Pauli operators;
- the half-filled Hubbard square closes to 70 states, including 16 retained spins;
- the fourth-order ring coefficient is `K = 20 t**4 / U**3`;
- reconstruction of the ring result from four-spin Pauli strings;
- Boolean projector reduction and pointwise diagonal inversion;
- packed fermion multiplication and adjoint against `NumberOrderedForm`;
- the Jordan-Wigner spin conversion at the readout boundary;
- direct source-to-target fermion action, including the phase from frozen filled modes;
- the published second-order bare and spectator-assisted Crépel-Fu hopping;
- `O(t0**6)` spectral error between the fourth-order effective Hamiltonian and exact
  diagonalization of the one-A reference cluster;
- the connected range-two Crépel-Fu hopping on two overlapping A stars, including
  its exact symbolic fourth-order coefficient and absence at second order;
- preservation of positive and negative Floquet shifts after the single carrier
  rotation;
- the finite and algebraic spin-1 3x3 blocks through second order;
- sparse-map composition and adjoint against exact matrix operations;
- canonical off-diagonal map storage with a formal, non-eager `Q` projector;
- package-level `OperatorMap` storage as canonical sums of `Q X W A` terms with
  explicit left/right spaces;
- a nonlinear `n = 2m` boson embedding stored as one algebraic map term;
- affine-band adjoint without inverting the occupation relation;
- exact two-axis compression of hybrid operator-band components;
- native NOF and packed tensor-factor multiplication with finite matrices outside the
  operator algebra;
- a bosonic target block and right map action that remain number ordered;
- full target-matrix agreement of the map backend for the coupler, ring, Floquet, and
  connected two-star Crépel-Fu models.

The finite-state reference backend continues to use tuple occupations. The historical
implicit backends and the production package path avoid materializing the complete
source Hilbert space. Together the reference implementations cover finite spins,
finite multilevel blocks, fermion sectors, bosons, and ladders while the package path
keeps number-ordered operators as its native algebraic output.
